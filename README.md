# 🚀 100 Days of DSA Challenge in Java

Welcome to my **100 Days of Data Structures and Algorithms (DSA) Challenge!**

I completed 100 days of consistent coding practice using Java to improve my problem-solving skills, understand important DSA concepts, and prepare for technical interviews.

🔗 **GitHub Repository:** [100_Days_DSA_Challenge](https://github.com/AnujIndulkar/100_Days_DSA_Challenge)

## 🎯 Goals

- Practice Data Structures and Algorithms consistently.
- Improve problem-solving and logical thinking.
- Implement brute-force and optimized solutions.
- Understand time and space complexity.
- Prepare for coding assessments and software developer interviews.

## 🛠️ Technologies Used

- **Programming Language:** Java
- **Practice Platform:** LeetCode
- **IDE:** VS Code
- **Version Control:** Git and GitHub

## 📚 Topics Covered

- Arrays and Strings
- HashMap and HashSet
- Two Pointers and Sliding Window
- Stack and Queue
- Linked Lists
- Recursion and Backtracking
- Binary Trees and Binary Search Trees
- Tree Traversals: BFS and DFS
- Greedy Algorithms
- Dynamic Programming
- Searching and Sorting

## 💡 Problem-Solving Approach

For selected problems, I practiced:

1. **Brute Force:** Understand the basic logic and approach.
2. **Optimal Solution:** Improve algorithm efficiency.
3. **Complexity Analysis:** Evaluate time and space complexity.
4. **Java Implementation:** Write readable code and test example cases.
